# Hero frame assets

The current extracted frames live in the `Risol/` subfolder and use this naming convention:

`Risol/ezgif-frame-001.jpg` through `Risol/ezgif-frame-091.jpg`

The React canvas loader will preload all frames and use them as a scroll-driven animation. Until the assets are present, the site shows a lightweight CSS fallback object so local development remains usable.
